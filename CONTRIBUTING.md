# Contributing to Mati-Metsi

This is a hackathon project but contributions are welcome.

## Development
1. Open `index.html` in any modern browser — there is no build step.
2. Changes are tested against Chrome, Firefox and Safari.
3. Keep the single-file structure — no external dependencies.

## Code style
- 2-space indentation
- Single quotes for strings in JS
- Escape user content with `esc()` before inserting into the DOM
- No `eval`, `new Function`, or `innerHTML` on user input

## Reporting issues
Use the issue templates in `.github/ISSUE_TEMPLATE/`.
