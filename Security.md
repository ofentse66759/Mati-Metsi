# Security Policy

This project was developed following a Secure System Development Life Cycle (SSDLC). The full risk assessment, STRIDE threat model, secure-coding practices, testing performed, and integration plan are documented below.

## Reporting a vulnerability

This is a hackathon demonstration. For production use, contact **security@mati-metsi.org**.
Do not open a public issue for security concerns.
